title: "Platform API"
description: "Authenticate with a workspace API key and call the Jam REST API over HTTPS."
---

The Jam Platform API lets you read your AI-visibility data and manage your tracked prompts and brand profile from your own scripts, dashboards, and agents. Every endpoint is documented in the **API Reference** tab, created directly from the live OpenAPI spec so it never drifts from what the API serves.

## Get an API key

1. Open your Jam workspace and go to **Settings**, then **Developer**.
2. Click **Create API key** and give it a name.
3. Copy the key. It is shown once. Keys look like `sk_` followed by 64 hex characters and reach the workspace's real data; there are no test keys.

An agent can also get a key for a human with one link: see [agent connect](/agents/quickstart#1-get-an-api-key).

<Note>
  Keys are scoped to the workspace that created them. Revoking a key takes effect immediately.
</Note>

## Base URL and auth

```http
https://api.spreadjam.com
```

Send your key as a bearer token on every request:

```http
Authorization: Bearer $JAM_API_KEY
```

A missing or invalid key returns `401`. Every error uses the same body, with a stable `code` and a `requestId`: see [Errors and limits](/api-reference/errors).

## Try it

```bash
export JAM_API_KEY=sk_your_key_here

# Confirm your key and see which workspace it resolves to.
curl -sS https://api.spreadjam.com/v1/me \
  -H "Authorization: Bearer $JAM_API_KEY" | jq
```

## Explore the endpoints

Browse the full, always-current reference in the **API Reference** tab. It covers your identity (`/v1/me`), AI-visibility analytics, keyword and topic rankings, your brand profile and competitors, and tracked prompts, each with parameters, response schemas, and a request builder. The machine-readable spec is served at [`https://api.spreadjam.com/openapi.json`](https://api.spreadjam.com/openapi.json).

## Use with Claude, ChatGPT and other agents

The Jam MCP server at `https://api.spreadjam.com/mcp` exposes every endpoint as a tool.

- **Claude.ai or Claude Desktop:** **Settings**, **Connectors**, **Add custom connector**, then enter `https://api.spreadjam.com/mcp`. Claude opens a Jam page in your browser: sign in, check the workspace, and approve. No key is needed.
- **ChatGPT:** add a connector (developer mode) with the URL `https://api.spreadjam.com/mcp` and OAuth authentication, then sign in and approve the same way.
- **Claude Code:**

  ```bash
  claude mcp add --transport http jam https://api.spreadjam.com/mcp --header "Authorization: Bearer $JAM_API_KEY"
  ```

A connector shows up in **Settings**, **Developer** as a key named after the client, for example "Claude (connector)". Revoke it there to disconnect. See [Quickstart for agents](/agents/quickstart) for Cursor and other clients, and [How to operate Jam](/agents/operating-guide) for instructions to give your agent.
