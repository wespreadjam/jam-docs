title: "WorkflowRunner"
description: "Programmatic workflow execution with topological sort, real-time status, and abort support."
---

## Overview

`WorkflowRunner` executes workflows programmatically. It handles execution order via topological sort (Kahn's algorithm), conditional branching, and real-time status callbacks.

```typescript
import { WorkflowRunner } from '@jam-nodes/editor';

const runner = new WorkflowRunner(registry, {
  stopOnError: true,
  onStatus: (nodeId, status) => console.log(nodeId, status.status),
});

const result = await runner.run(workflowJSON);
console.log(result.success, result.totalDurationMs);
```

## Constructor Options

```typescript
interface WorkflowRunnerOptions {
  stopOnError?: boolean;    // Stop on first error (default: false)
  onStatus?: StatusCallback;  // Real-time status updates
}

type StatusCallback = (nodeId: string, status: NodeStatus) => void;
```

## Running a Workflow

```typescript
const result: RunResult = await runner.run(workflowJSON);
```

### RunResult

```typescript
interface RunResult {
  success: boolean;                        // True if no errors
  nodeStatuses: Map<string, NodeStatus>;   // Final status of each node
  totalDurationMs: number;
}
```

### NodeStatus

```typescript
interface NodeStatus {
  nodeId: string;
  status: 'idle' | 'running' | 'success' | 'error' | 'skipped';
  output?: unknown;
  error?: string;
  durationMs?: number;
}
```

## Aborting Execution

```typescript
runner.abort();
console.log(runner.isRunning); // false
```

## Execution Logic

<Steps>

### Topological Sort

Nodes are sorted based on edge dependencies using Kahn's algorithm. Disconnected or cycle nodes are appended at the end.

### Input Resolution

For each node, inputs are resolved by merging static config with edge-connected upstream outputs.

### Execution

Each node is executed via `registry.getExecutor(type)`. Output is stored in an `ExecutionContext` for downstream nodes.

### Conditional Branching

If a node returns `nextNodeId` (e.g., the conditional node), only the selected branch continues. Non-selected branches are marked as `skipped`.

</Steps>
