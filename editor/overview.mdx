## Installation

```bash
npm install @jam-nodes/editor @xyflow/react react react-dom
```

## WorkflowEditor Component

The main component that wraps everything in a `ReactFlowProvider`.

```tsx
import { WorkflowEditor } from '@jam-nodes/editor';
import { NodeRegistry } from '@jam-nodes/core';
import { builtInNodes } from '@jam-nodes/nodes';

const registry = new NodeRegistry();
registry.registerAll(builtInNodes);

<WorkflowEditor
  registry={registry}
  storageKey="my-workflow"
  onChange={(wf) => console.log('Updated:', wf)}
/>
```

### Props

<ParamField body="registry" type="NodeRegistry" required>
  Registry with all node definitions. Determines available nodes in the palette.
</ParamField>
<ParamField body="initialWorkflow" type="WorkflowJSON">
  Starting workflow. Overridden by localStorage if `storageKey` is set and data exists.
</ParamField>
<ParamField body="onChange" type="(workflow: WorkflowJSON) => void">
  Called on every workflow change (node add/remove/move, edge change, config edit).
</ParamField>
<ParamField body="storageKey" type="string">
  localStorage key for auto-persistence. Stored under `jam-editor:{storageKey}`.
</ParamField>

### Features

- **Drag-and-drop** nodes from palette onto canvas
- **Node config panel** — auto-generates form fields from Zod input schemas
- **Undo/redo** — full history stack
- **Export/import** — download/upload workflow JSON
- **Clear** — reset canvas
- **Zoom controls** — zoom in/out/fit
- **Run/Stop** — execute workflow in-browser via `WorkflowRunner`
- **Execution visualization** — nodes show running/success/error/skipped states
- **Execution result panel** — shows outputs and errors per node

<Tip>
  When `storageKey` is provided, workflows auto-save to `localStorage` so they persist across page reloads. The stored workflow takes priority over `initialWorkflow` on mount.
</Tip>

## Sub-components

The editor is composed of these internal components:

| Component | Purpose |
|-----------|---------|
| `NodePalette` | Sidebar listing all registered nodes by category. Drag source. |
| `WorkflowCanvas` | React Flow canvas with custom node rendering and edge handling. |
| `NodeConfigPanel` | Right panel auto-generating form fields from Zod schema introspection. |
| `WorkflowToolbar` | Top bar with name, undo/redo, zoom, import/export, run/stop. |
| `ExecutionResultPanel` | Shows per-node execution results after a run. |
| `CustomNode` | React Flow node component with handles for each input/output field. |

## Schema Introspection

The editor auto-generates config forms using `ZodSchemaIntrospector`:

```typescript
import { introspectSchema } from '@jam-nodes/editor';

const fields = introspectSchema(myNode.inputSchema);
// SchemaFieldInfo[] with name, type, required, description, enumValues, children, etc.
```

```typescript
interface SchemaFieldInfo {
  name: string;
  type: 'string' | 'number' | 'boolean' | 'enum' | 'array' | 'object' | 'unknown';
  required: boolean;
  description?: string;
  defaultValue?: unknown;
  enumValues?: string[];
  children?: SchemaFieldInfo[];
}
```

Handles `ZodOptional`, `ZodDefault`, `ZodNullable` wrappers. Recursively introspects nested objects and array item types.
